Project Overview

Slay The Nightmares to gra akcji typu beat ’em up utrzymana w stylistyce 2.5D. Gracz wciela się w jednorożca walczącego z falami koszmarów, używając rogu zdolnego przybierać różne formy broni. Celem rozgrywki jest przetrwanie dziesięciu intensywnych fal przeciwników.

My Role

Odpowiadałem za pełną stronę techniczną gry — od implementacji mechanik walki i ruchu, po systemy przeciwników, logikę UI oraz transformacje broni. Przygotowałem sceny pod styl 2.5D, shadery i efekty VFX oraz opracowałem wizualizacje koszmarów z użyciem Shader Graph.

// Example: Weapon Transformation System
public class WeaponForm : MonoBehaviour
{
    [SerializeField] private WeaponType currentForm;
    [SerializeField] private GameObject[] forms;

    public void SwitchForm(WeaponType newForm)
    {
        if (newForm == currentForm) return;

        forms[(int)currentForm].SetActive(false);
        currentForm = newForm;
        forms[(int)currentForm].SetActive(true);
    }
}
